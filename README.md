Yau-Yau filtering algorithm is designed to solve the problem of a filtering system of the form:


'''math
\left \{
\begin{array}{l}
dX_t = f(X_t)dt + \sigma_X dW_t\\[1mm]
dY_t = h(X_t)dt + dV_t
\end{array}
\right.
'''
